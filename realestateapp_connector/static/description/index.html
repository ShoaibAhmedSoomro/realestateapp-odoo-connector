Connecting used to take four values and two tabs

Setting up an integration by hand means finding your web address, your database name, the login to connect as, and an API key — then copying them into another application without typing any of them wrongly. Two of those are genuinely hard: the database name is not shown anywhere in the Odoo interface, and the API key needs a password confirmation and is displayed only once.

This app runs inside your Odoo, so it already knows all four. You paste one short code and press Connect.

How it works

1

In RealEstateApp, open Connectors → Odoo and press Get a pairing code.

2

In Odoo, open Settings → RealEstateApp, paste the code, and press Connect.

That is the whole setup. The app generates its own API key, works out which of your apps it can read, and tells RealEstateApp where to find you.

What it reads

Contacts Names, emails, phone numbers and job titles from Odoo Contacts.
CRM leads Opportunities and leads — offered only if you have the CRM app installed.

Your credentials stay yours

  • Your password is never used or sent. The app generates an API key for the integration instead.
  • Read only. Nothing is written back into your Odoo.
  • Revoke at any time. Press Disconnect, or delete the key under My Profile → Account Security. Either stops access immediately.
  • Nothing is claimed on trust. RealEstateApp verifies the key against your own Odoo before storing anything, so a connection never reports success it has not proved.

What it adds to your database

Nothing. No new models, no new tables, no new menus — it is a settings panel and two buttons. Uninstalling leaves only the API key behind, and Disconnect revokes that for you.

Requirements

Odoo 18.0, on Odoo.sh or your own server.

Odoo Online (the odoo.com hosted service) does not allow third-party modules to be installed. If that is your hosting, RealEstateApp still connects — you enter the four values manually on its Connectors screen instead.
